# Day Distiller 使用指引

日常流程集中在桌面应用的四个页面中：

1. **开始**：连接设备，导入记录，选择一天生成日记。
2. **回忆**：查看、编辑或重新生成已经保存的日记。
3. **形象与风格**：选择参考形象与海报风格。
4. **设置**：填写 AI 和邮件服务信息，或进入开发者设置体验离线演示。

第一次使用时，可以先复制一份设备记录，在开发者设置中选择这份记录并开启“离线演示”。连接设备后，用 USB 导入记录，再从“开始”页生成当天日记。

其他设置见 [AI 服务](mainland-model-setup.md)、[OpenAI](openai-setup.md)、[邮件](smtp-setup.md)和[形象与风格](avatar-setup.md)。遇到设备或媒体文件问题时参阅[排查指南](usb-ffmpeg-troubleshooting.md)。
