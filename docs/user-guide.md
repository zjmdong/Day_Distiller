# Day Distiller v2 用户指引

## 第一次使用

1. 打开“设置”页，依次填写阿里云百炼、DeepSeek、火山方舟的 Base URL、API Key 和模型名。默认模型分别为 `qwen3.7-plus`、`qwen3.5-omni-plus`、`deepseek-v4-pro`；Seedream 请使用火山控制台中实际开通的 Model ID 或 Endpoint ID。
2. 注册 Resend，添加自己拥有的域名，并按控制台提示设置 SPF、DKIM 等 DNS 记录。域名验证完成后创建 API Key。
3. 在应用设置页填写 Resend SMTP 参数：主机 `smtp.resend.com`、SSL/TLS端口 `465`（或STARTTLS端口 `587`）、API Key、发件地址和日报收件地址。SMTP用户名固定为 `resend`，API Key作为SMTP密码。发件地址的域名必须与 Resend 已验证域名完全一致。
4. 在“形象与风格”页上传一张清晰的单人正面或半身照片，填写简短形象描述，再从5个内置艺术风格中选择一个；也可输入不超过200字的自定义风格。最多只发送3张图片，当天选出两个Moment时可把参考形象作为第三张输入。

API Key 只保存在系统安全凭据库（Windows Credential Manager / macOS Keychain），并会在本机设置页明文回显。不要通过聊天、截图或 Git 提交密钥；查看设置页时注意旁人和录屏软件。

## 每天使用

1. 出门时携带并启动设备。
2. 回家后手动唤醒设备并连接电脑。
3. 在“设备”页确认设备连接成功。
4. 在“记录”页选择日期并检查记录数量。
5. 在“生成”页选择真实云端工作流，点击从设备开始生成。
6. 等待导入、预处理、Moments聚合、全天筛选、单张海报生成、排版和邮件发送完成。系统只选2–3个最值得回看的Moment，生成一张无文字3:4竖版海报。
7. 想尝试另一种艺术风格时，回到“形象与风格”，选择一条成功日报并生成试片。试片只调用一次Seedream，不重跑全流程，也不覆盖或发送原日报。
7. 在“报告历史”页打开日报；需要时可修改地点和文字、重新生成或重新发送。

## 内置组件

- FFmpeg和FFprobe随软件分发，用户不需要安装或设置路径。
- IMU首版使用内置方向无关启发式分类器，不需要选择 `.joblib` 文件。
- 地点记忆使用本地SQLite和图片签名，不调用额外模型。

## Resend常见问题

- `550/553 sender rejected`：检查发件地址域名是否与Resend中验证的域名或子域名完全一致。
- 只能发给自己：测试域名 `onboarding@resend.dev` 有收件限制；向其他地址发送前需要验证自己的域名。
- 重试收到重复邮件：应用同时发送确定性的 `Message-ID` 和 Resend 官方支持的 `Resend-Idempotency-Key`，降低崩溃重试造成的重复邮件；超过Resend幂等保护窗口后，手动重发仍会被视为新邮件。
- 邮件图片不显示：应用使用CID把海报内嵌在HTML中，同时把原始JPEG海报作为普通附件发送；部分严格客户端仍可能默认折叠内嵌图，可直接查看同名附件。
- 邮件超过限制：Resend附件经过Base64编码后的总大小上限为40MB。原始JPEG海报与PDF都会作为附件发送。
