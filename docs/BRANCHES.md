# Branches / 分支说明

The current firmware and desktop app live on separate branches. The older branches remain available as development history.

| Branch | Purpose |
| :--- | :--- |
| [firmware-production](https://github.com/zjmdong/Day_Distiller/tree/firmware-production) | Current firmware and project documentation |
| [desktop-app](https://github.com/zjmdong/Day_Distiller/tree/desktop-app) | Current desktop companion |
| [firmware-dev](https://github.com/zjmdong/Day_Distiller/tree/firmware-dev) | Firmware development |
| [old/usb-link-dev-firmware](https://github.com/zjmdong/Day_Distiller/tree/old/usb-link-dev-firmware) | Earlier USB firmware work |
| [old/windows-dev-client-py](https://github.com/zjmdong/Day_Distiller/tree/old/windows-dev-client-py) | Earlier Windows USB client |

For a new build, start with [firmware-production](https://github.com/zjmdong/Day_Distiller/blob/firmware-production/README.md) and the [desktop-app](https://github.com/zjmdong/Day_Distiller/blob/desktop-app/README.md).
