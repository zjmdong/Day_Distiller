# 参考形象与艺术风格

参考形象用于保持海报主角的服装、发型和整体气质一致，不用于人脸识别。可以上传用户自己的实拍图，也可以上传已经满意的AI角色图；实拍图更贴近本人，AI角色图更容易维持稳定的插画形象。

## 拍摄建议

1. 使用均匀自然光，避免强逆光、滤镜和过度美颜。
2. 拍摄半身或全身，人物占画面 50%–80%，背景简洁。
3. 正面或轻微侧身，表情自然；不要包含其他人。
4. 穿着能代表日常形象的服装，避免清晰身份证件、门牌、工牌和屏幕隐私。
5. 使用 JPG、PNG 或 WebP。建议至少 1024 像素长边、文件大小不超过约 10 MB。

## 导入

在“形象与风格”页选择图片并保存。Seedream请求严格限制为最多3张输入图：优先保留入选Moment的事实画面；当天只选出2张画面时，参考形象会使用余下的第3个位置。文字形象描述始终作为非生物特征提示。更换参考资料不会自动改写旧成品。

## 艺术风格

应用内置扁平色块波普、电影感写实、当代漫画、抽象极简、诗意拼贴五种风格。每个预设都同时约束构图、色彩、材质、线条和应避免的失真，不只是添加一个风格名称。

选择“自定义风格”时，可以输入不超过200字的中文或英文提示。只描述希望的材质、色彩、笔触、光线和情绪；竖版3:4、无文字、事实一致等安全边界由应用统一追加。

想先看效果时，在同一页面选择一条已经成功完成的历史日报，点击“只生成一张风格试片”。这个操作复用已经保存的场景证据、入选Moment和海报构图提示，只调用一次Seedream，不会重新跑Qwen、DeepSeek、IMU、PDF或邮件，也不会覆盖旧日报。

如果不愿上传真人参考图，可以留空；应用会生成通用日记角色。也可以使用自行制作、拥有使用权的插画角色。请勿导入无授权人物照片。
